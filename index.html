동국대학교 통계학과 · 소프트웨어 AI 연계전공 · 학부 재학

데이터를 다루고,
AI 모델의 결과를 검증하고,
실제 쓰이는 서비스로 만듭니다.

통계학을 전공하면서 데이터를 정리하고 해석하는 방법을 배웠고, 소프트웨어 AI 연계전공과 인턴 경험을 통해 모델을 직접 학습·평가하고 사용자가 쓰는 화면까지 만들어 봤습니다. 결과 숫자보다 그 숫자가 나온 조건을 먼저 확인하는 편입니다.

  • 데이터수집·전처리·품질 검증
  • 검증모델 평가와 실행 조건 확인
  • 서비스기획부터 배포까지 구현

소개

무엇을 하는 사람인지

통계학과 소프트웨어 AI를 함께 공부하면서, 데이터 한쪽 끝에서 다른 쪽 끝까지 직접 만져 보는 일을 해 왔습니다. 데이터를 정리하고, 모델이 낸 결과가 믿을 만한지 확인하고, 그 결과를 사람이 쓸 수 있는 화면으로 옮기는 과정입니다. 세 가지를 따로 배우기보다 하나의 흐름으로 경험한 것이 지금까지의 작업 방식이 됐습니다.

조건을 먼저 확인합니다

같은 지표라도 어떤 데이터, 어떤 설정에서 측정했는지에 따라 값이 달라집니다. 결과를 비교하기 전에 비교할 수 있는 상태인지부터 확인합니다.

다시 실행할 수 있게 남깁니다

한 번 돌아간 작업보다 다음 사람이 같은 결과를 낼 수 있는 작업이 쓸모 있다고 생각합니다. 실행 절차와 조건을 문서로 정리하는 일을 함께 합니다.

쓰는 사람까지 생각합니다

데이터를 화면에 띄우는 것과 실제 업무에 쓰이는 것은 다릅니다. 사용자의 요청을 받아 기능과 화면을 고쳐 본 경험이 있습니다.

관심 영역 — 데이터 분석 및 검증 · AI 모델 학습과 평가 · 생성형 AI · 실제 사용 가능한 서비스 개발 · 기술 문서화와 재현 가능한 작업 환경

경험

일한 곳

2025.12 — 2026.07

인턴

SFACSPACE · 개발사업부 CV팀

정부지원 R&D 과제로 진행된, 한국 문화유산에 특화된 3D 에셋 생성 파이프라인 연구개발에 참여했습니다.

맡은 일

  • 학습·평가 데이터 전처리, holdout 구성과 데이터 누출 점검
  • image-to-3D 모델(TRELLIS2)의 LoRA 파인튜닝과 체크포인트별 결과 비교
  • 정량 평가 수행, 평가 코드와 실행 조건이 의도대로 동작하는지 검증
  • 앞단 이미지 생성 모델을 바꿔 가며 조건 이미지 품질 비교
  • 생성 파이프라인 실행과 결과 점검
  • 재현 가능한 실행 문서와 인수인계 문서 작성
  • 시장조사, 사업계획서 자료 조사, 발표자료 제작, 서비스 소개 랜딩페이지 제작

이 과정에서 확인한 것

  • 평가 지표 값만 보지 않고, 그 값이 어떤 데이터와 설정에서 계산됐는지 함께 확인해야 비교가 성립한다는 점
  • 학습 데이터와 평가 데이터가 섞이지 않도록 기준을 정해 두는 일이 결과의 신뢰도를 좌우한다는 점
  • 실행 조건을 문서로 남겨 두면 같은 작업을 다른 사람이 이어받을 수 있다는 점

사내 과제로 진행되어 코드, 데이터, 세부 수치는 공개하지 않습니다.
